# Project layout

```
<film-name>/
  brief.md            # kickoff answers: length, aspect, budget, music, subs, references
  story.md            # one-sentence message + shot-by-shot story (locked version noted)
  shots.md            # shot table
  palette.md          # per-scene colour table
  sketches/           # colour-block sketches, contact sheet, greyscale contact sheet
  style/              # style frames, character + prop sheets
  frames/shotNN/      # first_vK.png, last_vK.png, frames-plan.md
  prompts/shotNN_vK.txt
  clips/shotNN_vK.mp4 # every take kept
  post/               # lossless intermediates, scripts
  reviews/            # every reviewer verdict, with date
  decisions.md        # every decision + spend; user can overturn anything
  spend.log
  out/                # deliverables
  RETRO.md
```
Versioning: never overwrite. `_v1`, `_v2`, ...
